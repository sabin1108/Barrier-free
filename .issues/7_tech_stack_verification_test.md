## What to build

지식 기반 검증 레이어의 올바른 작동을 테스트하기 위해, 의도적으로 오타가 나거나 허구인 가짜 기술명, 표준 명칭이 아닌 약어 등이 포함된 후보 리스트를 입력했을 때 시스템이 알맞게 보정 및 필터링 처리를 해내는지 검증하는 단위/통합 테스트를 작성합니다.

## Acceptance criteria

- [ ] 비표준 기술 스택 약어 입력 시 DB 별칭 매핑을 통해 정식 표준 명칭(예: JS -> JavaScript)으로 자동 치환되는지 검증할 수 있어야 함
- [ ] 데이터베이스 지식 베이스에 전혀 존재하지 않는 허구의 기술명이나 오타가 입력되었을 때 자동으로 필터링 및 제외 처리가 진행되는지 검증되어야 함
