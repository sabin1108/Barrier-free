## What to build

관리자 회원가입 절차의 보안을 강화하기 위해 등록 단계에서 Input OTP 컴포넌트를 이용한 2단계 인증 절차와 사용자 인터페이스(UI) 및 검증 흐름을 구현합니다.

## Acceptance criteria

- [x] Tailwind CSS v4 및 Radix UI 기반의 원자적 Input OTP 컴포넌트가 정상적으로 렌더링되어야 함
- [x] 입력받은 일회성 비밀번호(OTP)에 대한 서버사이드 검증 로직이 동작해야 함
- [x] OTP 검증을 성공적으로 통과한 사용자만 가입 및 세션 생성이 승인되어야 함

## Blocked by

None - can start immediately
