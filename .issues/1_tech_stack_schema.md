## What to build

사용자 프로필 및 프로젝트 요약 시 기술 스택(태그)의 신뢰성을 확보하기 위해, 사전에 표준화된 기술 스택 명칭 및 별칭(Alias) 정보를 담는 지식 베이스(Knowledge Base) 스키마를 구성하고 초기 시드 데이터를 적재합니다.

## Acceptance criteria

- [ ] 표준 기술 스택 정보를 관리하는 스키마/테이블 설계가 완료되어야 함
- [ ] 비표준 별칭(예: JS, ReactJS)을 표준명(JavaScript, React)으로 매핑하기 위한 관계 또는 컬럼이 정의되어야 함
- [ ] 주요 프론트엔드, 백엔드, 데이터베이스 등의 핵심 기술 스택 후보군에 대한 초기 시드 데이터 적재가 성공적으로 이루어져야 함

## Blocked by

None - can start immediately
