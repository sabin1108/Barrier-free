## What to build

생성형 AI(GPT-4o-mini)가 비정형 프로젝트 데이터에서 추출한 임시 기술 스택 배열을 받아, 지식 베이스 테이블과 대조하여 표준명으로 보정하고 사전 정의되지 않은 유효하지 않은 기술명이나 오타(할루시네이션 결과물)는 자동으로 필터링하여 통과시키지 않는 검증 유틸리티 및 API 파이프라인을 구축합니다.

## Acceptance criteria

- [ ] AI 추출 기술 스택에 대해 표준명 보정 경로(Alias 매핑)를 정상적으로 거치도록 구현되어야 함
- [ ] 지식 베이스에 없는 오염된 데이터(가짜 기술명 등)를 원천 차단하고 필터링하는 로직이 적용되어야 함
- [ ] 검증을 마친 정형화된 데이터만 데이터베이스의 프로젝트 테이블(tags 컬럼)에 저장되도록 연동되어야 함
